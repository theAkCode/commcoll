#  CommColl – Student Collaboration Platform

**CommColl** is a web-based platform that helps students connect, collaborate on projects, and communicate effectively. Users can post their ideas, request to join other projects, and work together inside a shared chat space called a **WorkRoom**.

##  Features

-  Authentication via Google (GitHub optional)
-  Post and browse student-led projects
-  Request to collaborate on projects
-  Accept/reject collaboration requests (by project author)
-  WorkRoom – Group chat for accepted collaborators
-  Profile management with skills, education, and project history
- Dark mode support

##  Tech Stack

- **Frontend:** Next.js + Tailwind CSS
- **Backend & Realtime DB:** Firebase Firestore
- **Authentication:** NextAuth.js (Google)
